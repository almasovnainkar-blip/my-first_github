 Онлайн кітапхана
Жоба туралы
Онлайн кітапхана — пайдаланушыларға кітаптарды іздеуге, кітаптар туралы ақпарат алуға және оларды онлайн оқуға мүмкіндік беретін мобильді қосымша.
Жобаның негізгі мақсаты — кітап оқуды жеңілдету және пайдаланушыларға қажетті кітаптарды бір жерден табуға көмектесу.
 Жобаның мақсаты
Қазіргі уақытта кітаптарды іздеу және өзіңмен бірге алып жүру әрдайым ыңғайлы емес. Сондықтан біз кітаптарды телефон арқылы іздеп, оқуға болатын онлайн кітапхана жасадық.
 Қосымшаның жұмыс істеу тәртібі
	1.Пайдаланушы қосымшаны ашады.
	2.Телефон нөмірі мен құпия сөзін енгізіп, жүйеге кіреді немесе тіркелу бетіне өтеді.
	3.Кітаптар каталогынан қажетті кітапты таңдайды.
	4.Кітап туралы ақпаратпен танысады.
	5.«Кітапты оқу» батырмасын басып, кітап мәтінін оқиды.
	6.Таңдалған кітап «Менің кітаптарым» бөліміне сақталады.
	7.Жеке кабинеттен пайдаланушы өз мәліметтерін көре алады.
  Жобаның ерекшелігі
Қосымшада бірнеше функция бір жерге біріктірілген: кітап іздеу, санат бойынша таңдау, кітап оқу және жеке кітаптар тізімін басқару. Интерфейсі қарапайым әрі түсінікті жасалған.
 Болашақта дамыту жоспарлары
	•	Деректер қорын қосу.
	•	Пайдаланушылардың аккаунттарын сақтау.
	•	Кітаптарды таңдаулыларға қосу.
	•	Оқудың соңғы орнын есте сақтау.
	•	Кітаптарды PDF форматында оқу мүмкіндігін қосу.
	•	Жаңа кітаптарды үнемі толықтырып отыру.
